# qq-farm-bot-fnos

QQ 农场助手的 **飞牛 fnOS 原生应用（FPK）** 版本。

本项目 fork 自 [liyangpengs/qq-farm-bot](https://github.com/liyangpengs/qq-farm-bot)，在其基础上做了飞牛原生打包与网关适配，并增加了少量额外功能（见下方「额外功能」）。QQ 农场助手的核心功能均来自上游项目，感谢原作者及贡献者。

- 以飞牛原生进程运行，后端为自带运行环境的单文件可执行程序，**无需安装 Node.js**。
- **不开放任何端口**：服务只监听飞牛统一网关的 Unix Socket，从飞牛桌面图标「QQ 农场」或 `/app/qq-farm-bot/` 访问。
- **移除登录 / 改密模块**：应用内不再有管理员账号和密码，访问控制完全由飞牛登录负责。
- 数据保存在应用数据目录 `/vol*/@appdata/qq-farm-bot/data`。

## 额外功能

以下功能为本 fork 新增。设置类功能**按账号分别设置，默认关闭**。

「设置 → 大小号协作」：

- **大号/小号**：把账号设为小号并从好友中选择大号后，可打开「成熟作物先留给大号偷」（默认开）：小号的成熟作物先留给大号偷，检测到大号偷过才自动收获，可设置超时后仍收获；关掉则小号正常收获自己的地。手动收获不受限制。
- **不偷大号的菜**：小号自动巡查好友时不偷大号。
- **只给大号放捣乱**：小号的放草、放虫只对大号做，不对其他好友做（「自动捣乱」关着也会对大号放）；帮大号时有草/虫的地不帮，留给大号自己清。
- **偷收比**：生涯偷菜 ÷ 生涯收获 × 100%（与好友卡片「收偷比」同一组数据）。阈值默认 80%，超过才触发。可单独打开：拒绝高偷收比好友申请、好友页按偷收比筛选、高偷收比好友来偷菜时用现有 Bark 推送、自动删除高偷收比好友（大小号协作里的大号和小号不删）。四项默认关。
- **在线期间来偷菜的自动删除**（默认关，与偷收比阈值无关）：程序正在运行且这次上线之后，有好友来偷菜就删除。掉线、程序停止，以及重连后补拉到的历史记录不删。不删大号、本机登录过的小号。两次删除至少间隔 1 分钟。

「设置 → 自动控制」（本 fork 加的「图鉴」卡片，随「保存自动控制」一起保存）：

- **图鉴奖励自动领取**（默认开）：约每 30 分钟检查作物图鉴、变异图鉴，收到图鉴红点时提前，有可领的等级奖励就领取，日志写明领到什么。
- **自动完成图鉴**：找出作物图鉴里未收藏、背包里没有种子、地里也没种着的作物，从种子商店买 1 个种子（只买已解锁、等级够、不需要解锁卡、未售罄且金币够的；每次检查最多买 1 个，同时最多 2 个待种，同一种子最多自动买 3 次），下次自动播种时先把它种下，种下或收藏后恢复原来的播种顺序。会花金币，需要打开自动种植。

- **自己收菜优先**（默认开）：按自家下一块作物的成熟时间精确巡田，成熟前后好友巡查让路，连续成熟的地合并成一轮补种。开了「成熟作物先留给大号偷」的小号不受影响。
- **空闲时只保留心跳**（默认关）：农场和好友都没事可做时，在设定的分钟范围内随机静默，期间只保留连接心跳，牧场自动化也一起暂停；自家作物成熟前一定醒来。
- **按时间表偷菜**（默认开）：每隔「好友列表扫描间隔」（可填 1～60 分钟，默认 5 分钟）扫一遍好友，自家的活轮完后立刻把好友的农场和牧场状态过一遍，记下每个好友还多久能偷，到点直接去，顺手帮忙除草、除虫、浇水；农场、牧场好友列表每人显示「还多久可偷」倒计时（没在长的显示农场「空地」/ 牧场「暂无可偷」）。服务器不推送好友成熟，所以只能靠时间表。
- **自家到期前蹲点**：自己的作物和动物在成熟前「自家到期前提前」秒（默认 2 秒）过去等着，一熟就收。
- **农场、牧场严格轮流**：农场跑完一轮就去牧场，牧场跑完一轮就回农场；每边至少待 1 分钟，切换前 30 秒内这边有自己的东西要收就先等收完（最多多等 2 分钟）；任何一边有东西到点都可以插队，牧场一轮超过 10 分钟强制回农场。优先级：收自己的 → 偷好友的 → 帮忙 → 任务、图鉴、活动、每日福利、邮件、商店、偷收比统计、宠物同步等杂项（只在空闲时做）。
- **最后 X 块地只种牧草**（「日常农场」，默认 0 即关闭）：已解锁土地中编号最后的 X 块只种牧草，种子不够时可自动从商店补买。

「牧场 → 策略」页（2026.11.17.1 起随上游从牧场设置页移过来，随「保存牧场策略」一起保存）的「飞牛增强」卡片：

- **小号等大号**（默认开，只对开了「成熟作物先留给大号偷」的小号生效）：牧场货架的产物先留给大号偷，大号偷过或超时才一键收，期间只收成熟动物。
- **牧场图鉴 / 巨大图鉴奖励自动领取**（默认开）：约 30 分钟随牧场巡查检查一次，有红点时提前；另可打开「自动完成牧场图鉴」，自动买幼崽时优先买还没进图鉴的动物（默认关）。
- **帮好友生产**、**给好友加牧草**：随上游「好友互动」一起执行，默认关。加牧草默认用农场仓库的牧草（每份 1 个，仓库不够只加够库存的份数并暂停、写日志，不会改用金币）；「加草来源」可改成金币（约 60 金币/份，自己金币低于保留值不加）。
- 好友牧场的自动偷、清理、放蚊子、摸摸用上游「好友互动」开关；本 fork 只叠加大小号规则：小号「不偷大号的菜」不偷大号；「只给大号放捣乱」时只给大号放蚊子、不帮大号清理；其余情况不给自己的大号和小号放蚊子。

「设置 → 活动设置」：说明当前活动的位置。上游 2026-11-17 接入的「牧歌初启」在「牧场 → 活动」里手动操作，没有自动项；牧场「每日商城福利」开关在「牧场 → 策略」。原来的奶茶活动自动化（自动雇佣、工作事项、收益领取、森野种子兑换、自动制作、领工资、店铺自动升级）已于 2026-11-15 随奶茶活动下线而下架；游戏内奶茶活动页面仍是上游原样。

「设置 → 策略设置」：

- **背包种子优先顺序：改序号、拖动排序**：每行左边的序号可以点一下直接改，输入目标位置后回车或点别处即移过去，其他种子依次顺延（超出范围按第 1 位或最后一位算，输错了恢复原序号）；也可以按住序号右侧、上下箭头左边的拖动手柄（六个点）拖到想要的位置，拖动时有插入位置提示线和「移到第 N 位」气泡，拖到列表上下边缘会自动滚动。手机上只有按住手柄才拖动，其他地方照常滑动页面。原来的上/下箭头仍保留。

「设置 → 系统设置 → 下线提醒」（全局设置）：

- **Bark 静音也提醒（重要警告）**：推送渠道选 Bark 时出现此开关，默认开启。开启后账号掉线的提醒以 Bark「重要警告」发送（音量 5、铃声持续约 30 秒），手机静音或勿扰时也会响铃，「测试通知」同样按此设置发送；其他事件提醒仍为普通推送。需在 iPhone「设置 → 通知 → Bark」里允许「重要警告」。同时修复了 Bark（以及 PushPlus、WxPusher）推送成功却提示「测试失败: success」的问题。

「概览 → 运行日志」：

- **农场、牧场日志合成一张卡片**：顶部「全部 / 农场 / 牧场」切换（默认全部，记住上次选择），农场、牧场各用自己的筛选（含「农牧轮次」「图鉴奖励」「按时间表前往」等）。日志按账号、农场 / 牧场分开存到应用数据目录（农场 20000 条、牧场 3000 条，最近 3 天），重启不丢；牧场有「今日牧场」汇总（偷了谁、偷到什么、各动作次数，保留 7 天）。「暂不能拜访」「暂未执行」这类刷屏提示同一条每小时只记一次。总日志 combined.log 按天切分，只留 7 天。
- **偷菜日志 / 报错日志分栏**：运行日志分为「全部」「偷菜日志」「报错日志」三栏，原来的过滤器照常可用。偷菜日志收录偷到菜的好友访问、巡查总结、小号给大号留菜的记录。报错日志收录错误和警告，可选只看错误或只看警告。偷菜、报错两类日志各自最多保留最近 1000 条，不会被普通日志挤掉。

「我的农场」：

- **地块卡片直接施肥**：每块地的卡片上有「普通肥」「有机肥」按钮，点一下只给这一块地施肥；当前不能施肥时按钮变灰，悬停可看原因（如「当前作物无需施肥」「有机化肥次数已用完」）。受「设置 → 自动控制 → 显示手动施肥按钮」控制，进入「选择土地」时隐藏。上游的选地批量施肥和一键施肥照常可用。

「页头」：

- **游戏公告（只读）**：页头的公告图标可查看当前账号的游戏公告标题列表，点开看全文、起止时间和封面图。只读取，不会替你标记已读；账号需已启动并登录。
- **界面固定浅色**：去掉深色模式和主题切换，界面始终为浅色。概览页「运行日志」卡片的底边与「今日统计」对齐，日志多时在卡片内滚动。

执行结果会写在日志里。详细说明见变更说明中的 2026.10.20.1、2026.10.21、2026.10.21.1、2026.10.21.2、2026.10.21.3、2026.10.21.4、2026.10.22、2026.10.22.1、2026.10.27、2026.10.27.1、2026.10.29、2026.10.29.1、2026.10.30、2026.10.31、2026.11.1、2026.11.2、2026.11.2.1、2026.11.16.1、2026.11.16.2、2026.11.16.4、2026.11.16.5 和 2026.11.17.1 各节。

## 安装

1. 从 [Releases](https://github.com/Maksim-venus/qq-farm-bot-fnos/releases) 下载 `qq-farm-bot_<版本>_native_x86.fpk`，并核对 SHA-256。版本号就是构建日期，例如 `2026.10.19`；同一天再发一版时依次加 `.1`、`.2`……（如 `2026.10.19.1`）。数字逐段越大越新，应用中心可直接覆盖升级。
2. 打开「应用中心 → 手动安装」，选择该 FPK；已安装旧版时确认覆盖升级。
3. 安装完成后从桌面图标「QQ 农场」打开。

自行构建：`pnpm install && fnos/build.sh`，产物在 `fnos/out/`。详细说明见 [`fnos/飞牛部署与变更说明.md`](fnos/飞牛部署与变更说明.md)。
