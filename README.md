# qq-farm-bot-fnos

QQ 农场助手的 **飞牛 fnOS 原生应用（FPK）** 版本。

本项目 fork 自 [liyangpengs/qq-farm-bot](https://github.com/liyangpengs/qq-farm-bot)，在其基础上做了飞牛原生打包与网关适配，并增加了少量额外功能（见下方「额外功能」）。QQ 农场助手的核心功能均来自上游项目，感谢原作者及贡献者。

- 以飞牛原生进程运行，后端为自带运行环境的单文件可执行程序，**无需安装 Node.js**。
- **不开放任何端口**：服务只监听飞牛统一网关的 Unix Socket，从飞牛桌面图标「QQ 农场」或 `/app/qq-farm-bot/` 访问。
- **移除登录 / 改密模块**：应用内不再有管理员账号和密码，访问控制完全由飞牛登录负责。
- 数据保存在应用数据目录 `/vol*/@appdata/qq-farm-bot/data`。

## 额外功能

以下功能为本 fork 新增。设置类功能**按账号分别设置，默认关闭**。

「设置 → 大小号协作」：

- **大号/小号**：把账号设为小号并从好友中选择大号后，可打开「成熟作物先留给大号偷」（默认开）：小号的成熟作物先留给大号偷，检测到大号偷过才自动收获，可设置超时后仍收获；关掉则小号正常收获自己的地。手动收获不受限制。
- **不偷大号的菜**：小号自动巡查好友时不偷大号。
- **只给大号放捣乱**：小号的放草、放虫只对大号做，不对其他好友做（「自动捣乱」关着也会对大号放）；帮大号时有草/虫的地不帮，留给大号自己清。

「设置 → 活动设置」：

- **奶茶活动自动雇佣**：员工位空出时自动雇佣好友，任何账号都可开启，不依赖大小号设置。可从好友里按顺序指定多个「优先雇佣人」（可搜索添加、拖动或上下按钮调整顺序）：有空位时按顺序先雇当前空闲的优先雇佣人，他们都不空闲或没指定时随机雇其他好友。雇佣时长统一一个设置（4/12/24 小时或随机），雇谁都按它；职业可选或随机。旧版小号开了自动雇佣的，升级后默认把大号当作优先雇佣人，时长沿用原来的「雇佣时长」。约每 10 分钟检查一次，员工下班后约 1 分钟内补雇。会消耗奶茶券。
- **被雇佣后自动做工作事项**：本账号被别人雇佣时，每个兼职班次自动为老板做一次工作事项（约每 10 分钟检查一次），可指定或随机（随机只在宣传推广、花式摇杯、招牌试饮中选）。需要在被雇佣的账号上打开，例如 A 号雇了 B 号，就在 B 号上打开。
- **奶茶收益自动领取**：每小时领取一次奶茶店收益。
- **森野黄金芽种子兑换**：每天在奶茶活动兑换商店按剩余限购兑换森野黄金芽种子，会消耗兑换货币；已兑换、售罄或货币不足时当天跳过。

「设置 → 策略设置」：

- **背包种子优先顺序：改序号、拖动排序**：每行左边的序号可以点一下直接改，输入目标位置后回车或点别处即移过去，其他种子依次顺延（超出范围按第 1 位或最后一位算，输错了恢复原序号）；也可以按住序号右侧、上下箭头左边的拖动手柄（六个点）拖到想要的位置，拖动时有插入位置提示线和「移到第 N 位」气泡，拖到列表上下边缘会自动滚动。手机上只有按住手柄才拖动，其他地方照常滑动页面。原来的上/下箭头仍保留。

「设置 → 系统设置 → 下线提醒」（全局设置）：

- **Bark 静音也提醒（重要警告）**：推送渠道选 Bark 时出现此开关，默认开启。开启后账号掉线的提醒以 Bark「重要警告」发送（音量 5、铃声持续约 30 秒），手机静音或勿扰时也会响铃，「测试通知」同样按此设置发送；其他事件提醒仍为普通推送。需在 iPhone「设置 → 通知 → Bark」里允许「重要警告」。同时修复了 Bark（以及 PushPlus、WxPusher）推送成功却提示「测试失败: success」的问题。

「我的农场」：

- **地块卡片直接施肥**：每块地的卡片上有「普通肥」「有机肥」按钮，点一下只给这一块地施肥；当前不能施肥时按钮变灰，悬停可看原因（如「当前作物无需施肥」「有机化肥次数已用完」）。受「设置 → 自动控制 → 显示手动施肥按钮」控制，进入「选择土地」时隐藏。上游的选地批量施肥和一键施肥照常可用。

执行结果会写在日志里。详细说明见变更说明中的 2026.10.20.1、2026.10.21、2026.10.21.1、2026.10.21.2、2026.10.21.3、2026.10.21.4、2026.10.22、2026.10.22.1 和 2026.10.27 各节。

## 安装

1. 从 [Releases](https://github.com/Maksim-venus/qq-farm-bot-fnos/releases) 下载 `qq-farm-bot_<版本>_native_x86.fpk`，并核对 SHA-256。版本号就是构建日期，例如 `2026.10.19`；同一天再发一版时依次加 `.1`、`.2`……（如 `2026.10.19.1`）。数字逐段越大越新，应用中心可直接覆盖升级。
2. 打开「应用中心 → 手动安装」，选择该 FPK；已安装旧版时确认覆盖升级。
3. 安装完成后从桌面图标「QQ 农场」打开。

自行构建：`pnpm install && fnos/build.sh`，产物在 `fnos/out/`。详细说明见 [`fnos/飞牛部署与变更说明.md`](fnos/飞牛部署与变更说明.md)。
